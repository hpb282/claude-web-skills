# claude-web-skills

Six Claude Code Skills for building good-looking websites: HTML, CSS, JS, UI/UX and animation.

| Shortcut | Skill | Purpose |
|----------|-------|---------|
| `@design` | [`frontend-design`](.claude/skills/frontend-design/SKILL.md) | Định hướng thị giác khác biệt: kiểu chữ, bảng màu, bố cục. |
| `@polish` | [`interface-polish`](.claude/skills/interface-polish/SKILL.md) | Tinh chỉnh chi tiết giao diện & vi tương tác CSS (theo Jakub Krehel). |
| `@gsap` | [`gsap-animation`](.claude/skills/gsap-animation/SKILL.md) | Các kỹ năng GSAP chính thức: cốt lõi (core), dòng thời gian (timeline), kích hoạt theo cuộn chuột (ScrollTrigger), các tiện ích mở rộng (plugins). |
| `@motion` | [`motion-principles`](.claude/skills/motion-principles/SKILL.md) | Tạo mới / kiểm định chuyển động thông qua (phong cách của) Emil Kowalski, Jakub Krehel, Jhey Tompkins. |
| `@vercel` | [`vercel-guidelines`](.claude/skills/vercel-guidelines/SKILL.md) | Đánh giá (rà soát) theo Bộ nguyên tắc Giao diện Web của Vercel. |
| `@uipro` | [`ui-ux-pro-max`](.claude/skills/ui-ux-pro-max/SKILL.md) | Các phong cách, bảng màu, cặp kết hợp phông chữ và quy tắc UX có thể tìm kiếm (tra cứu) được. |
| `@all-web` | all six | Quy trình đầy đủ từ đầu đến cuối, xem tại [CLAUDE.md](CLAUDE.md) |

## Use

Open this repo in Claude Code, or copy `.claude/skills/` and `CLAUDE.md` into your own project. Type a shortcut in your message (`@design landing page for a bakery`) or call a skill directly (`/gsap-animation`).

`ui-ux-pro-max` needs Python 3 for its search script.
