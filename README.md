# claude-web-skills

Six Claude Code Skills for building good-looking websites: HTML, CSS, JS, UI/UX and animation.

| Shortcut | Skill | Purpose |
|----------|-------|---------|
| `@design` | [`frontend-design`](.claude/skills/frontend-design/SKILL.md) | Distinctive visual direction: type, palette, layout |
| `@polish` | [`interface-polish`](.claude/skills/interface-polish/SKILL.md) | Jakub Krehel's design-engineering details |
| `@gsap` | [`gsap-animation`](.claude/skills/gsap-animation/SKILL.md) | Official GSAP skills: core, timeline, ScrollTrigger, plugins |
| `@motion` | [`motion-principles`](.claude/skills/motion-principles/SKILL.md) | Create / audit motion through Emil Kowalski, Jakub Krehel, Jhey Tompkins |
| `@vercel` | [`vercel-guidelines`](.claude/skills/vercel-guidelines/SKILL.md) | Vercel Web Interface Guidelines review |
| `@uipro` | [`ui-ux-pro-max`](.claude/skills/ui-ux-pro-max/SKILL.md) | Searchable styles, palettes, font pairings, UX rules |
| `@all-web` | all six | Full pipeline, see [CLAUDE.md](CLAUDE.md) |

## Use

Open this repo in Claude Code, or copy `.claude/skills/` and `CLAUDE.md` into your own project. Type a shortcut in your message (`@design landing page for a bakery`) or call a skill directly (`/gsap-animation`).

`ui-ux-pro-max` needs Python 3 for its search script.

Upstream sources and licenses: [.claude/skills/SOURCES.md](.claude/skills/SOURCES.md).
